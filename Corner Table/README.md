## 📖 Overview

**Corner Table** is an elegant, minimalist digital menu web app built for modern artisan cafes and restaurants. It features editorial typography, smooth layout alignment with CSS flexbox dotted leaders, and a warm rustic color scheme inspired by boutique menus.

## ✨ Key Features

- 🎨 **Editorial Aesthetic**: Warm rustic color palette (`--cream`, `--paper`, `--rust`, `--olive`) with carefully selected typography (*Fraunces* + *Space Mono*).
- 📜 **Dotted Leader Effect**: Custom CSS pseudo-elements creating responsive dotted lines between menu items and prices.
- 📱 **Fully Responsive**: Adapts fluidly across desktop, tablet, and mobile screens.
- ⚡ **Zero Dependencies**: Lightweight, fast-loading vanilla HTML5 and CSS3.
- ♿ **Accessible & Semantic**: Built using standard HTML5 markup (`<header>`, `<main>`, `<section>`, `<footer>`).

## 🚀 Getting Started

To run this project locally on your machine:

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/corner-table.git
   ```

2. **Navigate to the project directory**
   ```bash
   cd corner-table
   ```

3. **Open `index.html` in your browser**
   - Double-click `index.html` or open it with Live Server in VS Code.
