# 🌐 Developer Portfolio & Web Log

A clean, responsive, editorial-style personal portfolio and daily web development log built using pure **HTML5** and **CSS3**.

Designed with a graph-paper backdrop, typographic hierarchy, commit-log timeline, and interactive dark/blue accents—no external JavaScript or heavy frameworks required.

---

## 🎨 Features & Highlights

- **⚡ Zero Frameworks**: Pure HTML & CSS with modular custom properties (CSS variables).
- **📖 Editorial Typography**: Powered by Google Fonts (*Bricolage Grotesque* & *Newsreader*).
- **📅 Commit Log Timeline**: Showcases recent projects and build dates in a git-log design pattern.
- **🏷️ Interactive Skill Pills**: Minimalist badge badges styled with high-contrast outlines.
- **📱 Fully Responsive**: Custom breakpoints tailored for desktop, tablet, and mobile devices.
- **♿ Accessible & Keyboard Friendly**: Includes focus rings, semantic markup, and `prefers-reduced-motion` compliance.
